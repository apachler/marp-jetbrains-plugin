# Support

Thanks for using **Marp for JetBrains**. Here's the fastest way to get help.

## I have a question

Open a thread in
[GitHub Discussions](https://github.com/apachler/marp-jetbrains-plugin/discussions).
Discussions are searchable and benefit other users with the same question.

## I think I found a bug

Open a [bug report](https://github.com/apachler/marp-jetbrains-plugin/issues/new?template=bug_report.md).
Please include the information requested in the template — without it the issue
is much harder to investigate.

## I want to suggest a feature

Open a [feature request](https://github.com/apachler/marp-jetbrains-plugin/issues/new?template=feature_request.md).
Briefly explain the problem you're trying to solve, not just the solution you
have in mind.

## I found a security issue

Please **do not** open a public issue. Report it privately via
[GitHub Security Advisories](https://github.com/apachler/marp-jetbrains-plugin/security/advisories/new)
or email `apachler@paan-systems.com` with subject
`[security] marp-jetbrains-plugin`. See [`SECURITY.md`](./SECURITY.md) for full
details.

## I want to contribute

See [`CONTRIBUTING.md`](./CONTRIBUTING.md) for development setup and the PR
checklist. By participating you agree to the
[Code of Conduct](./CODE_OF_CONDUCT.md).

## Response time

This project is maintained by a single person in their spare time. Bug reports
and security disclosures are prioritised; feature requests may take longer to
triage.
